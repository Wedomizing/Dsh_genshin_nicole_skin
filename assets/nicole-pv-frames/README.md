# 尼可 PV 原始截图

本目录保留 15 张未裁切截图，用于核对来源和重做裁切。当前安装包使用同级 `../nicole-pv-clean/` 中的 14 张 WebP，不含 01:26 的一张。

- 来源：[原神官方 B 站中文 PV《缄口的金弦》第一分 P](https://www.bilibili.com/video/BV1cX516vEu8/?p=1)，发布者「原神」（UID 401742377）。
- 获取日期：2026-09-06。
- 画质：1080P 高清（format 30080），1920 × 1080。
- 原始截图：15 张 RGB PNG，保持完整画幅，未裁切、缩放、调色、修补或移除原片字幕、标识。
- 取帧规则：各时间点之后的第一张可解码视频帧；实际帧时间记录在 `manifest.json`，偏差小于一帧。
- `contact-sheet.jpg` 是按照下表顺序排列的带标签预览；不能替代 PNG 原图作为背景资产。
- `SHA256SUMS` 提供素材、总览和清单校验值。
- 原视频及音轨不随仓库或安装包分发。
